## 🇺🇸 English

### 🚀 How it Works: The "Age = Investment" Rule
The core strategy of this calculator is that your monthly investment increases by €1 every year as you age (e.g., if you are 25, you invest €25/month; at 26, you invest €26/month). This approach aligns your savings with your professional growth and increasing income over time.

### ✨ Features
- **Multilingual Support**: Available in English, Portuguese, and Spanish.
- **Compound Interest**: Precise monthly calculations using the Future Value formula.
- **Inflation Adjustment**: Calculates "Real Purchasing Power" to show the value of future gains in today's money.
- **Interactive Visuals**: Dynamic charts powered by Chart.js and detailed results tables.
- **Print Friendly**: Optimized for printing or saving as a PDF report.

### 🛠️ How to Use
1. Clone or download this repository.
2. Open `index.html` in any modern web browser.
3. Select your preferred language.
4. Input your initial capital, current age, target age, expected annual return, and average inflation.
5. The results will update automatically as you change the values.

## 🇵🇹 Português

### 🚀 Como Funciona: A Regra "Idade = Investimento"
A estratégia central desta calculadora é que o seu investimento mensal aumenta 1€ a cada ano à medida que envelhece (ex: se tem 25 anos, investe 25€/mês; aos 26 anos, investe 26€/mês). Esta abordagem alinha as suas poupanças com o seu crescimento profissional e aumento de rendimentos ao longo do tempo.

### ✨ Funcionalidades
- **Suporte Multi-idioma**: Disponível em Inglês, Português e Espanhol.
- **Juros Compostos**: Cálculos mensais precisos utilizando a fórmula de Valor Futuro.
- **Ajuste de Inflação**: Calcula o "Poder de Compra Real" para mostrar o valor dos ganhos futuros no dinheiro de hoje.
- **Visualização Interativa**: Gráficos dinâmicos (Chart.js) e tabelas de resultados detalhadas.
- **Pronto para Impressão**: Otimizado para imprimir ou guardar como relatório em PDF.

### 🛠️ Como Usar
1. Clone ou descarregue este repositório.
2. Abra o ficheiro `index.html` em qualquer navegador web moderno.
3. Selecione o seu idioma de preferência.
4. Insira o seu capital inicial, idade atual, idade alvo, rentabilidade anual esperada e inflação média.
5. Os resultados serão atualizados automaticamente conforme altera os valores.

- **Visualización Interactiva**: Gráficos dinámicos (Chart.js) y tablas de resultados detalladas.
